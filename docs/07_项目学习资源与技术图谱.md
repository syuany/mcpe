## 一、 现代游戏服务端技术全景图谱 (Tech Matrix & Skill Tree)

本项目横跨“**现代底层语言、操作系统与高性能网络、游戏空间算法、分布式微服务架构**”四大核心技术领域：

### 1.1 现代 C++23 技能树
* **`std::expected<T, E>` 错误处理**：全面取代沉重且破坏控制流的 C++ 异常，在 `ByteBuffer` 与 `VarInt` 解码中以轻量级值传递表达业务成功与失败。
* **`std::span<const uint8_t>` 与 `std::string_view`**：实现网络缓冲区的零拷贝只读切片，杜绝堆内存小对象反复分配。
* **编译期 Concepts（概念约束）**：在 `ByteBuffer` 模板函数中约束参数必须满足 `std::integral` 或 `std::floating_point`，提升编译报错可读性并实现零开销重载特化。
* **严格 RAII 与移动语义（Move Semantics）**：通过 `std::move` 与传值（Pass-by-value）结合，彻底消除网络发送数据包时的深拷贝开销。

### 1.2 Linux 高性能网络架构技能树
* **I/O 多路复用演进**：透彻掌握 `select` / `poll` 到 `epoll` 的内核演进，深刻理解红黑树、就绪链表、LT（水平触发）与 ET（边缘触发）在工业界的差异。
* **Standalone Asio 异步范式**：深刻理解 `io_context` 反应器循环、`executor` 抽象与 **`strand` 串行化无锁机制**。
* **TCP 流式协议治理**：掌握滑动窗口、Nagle 算法、`TCP_NODELAY` 调优，精通基于 VarInt 长度定界帧的粘包与半包消除算法。

### 1.3 游戏空间同步算法技能树
* **20 TPS 物理节拍器（Fixed Timestep）**：基于 `std::chrono::steady_clock` 与时间累加器，消除操作系统时间片抖动引发的物理漂移。
* **九宫格 AOI（Area of Interest）空间索引**：将世界划分为网格，通过集合差集算法计算 `Enter`、`Leave`、`Move` 事件，将广播量从 $O(N^2)$ 降为 $O(1)$ 常数级。
* **紧凑内存压缩**：精通 Minecraft `ChunkSection` 调色板映射（Palette）与 64 位整数数组位打包（Bit-Packing）算法。

### 1.4 分布式与跨语言存储技能树
* **gRPC 跨语言通信**：C++23 网关与 Go 微服务（EnderVault）共享 Protobuf v3 契约。
* **Redis 缓存进阶**：精通 Cache-Aside 模式、延时双删、分布式互斥锁（SetNX）、防穿透/击穿/雪崩 SOP。
* **MySQL 事务与金融级对账**：InnoDB B+ 树索引优化、乐观锁版本控制与基于全局 UUID 幂等流水的防并发刷道具设计。

### 2.2 计算机经典著作必读指南
1. **《UNIX网络编程 卷1：套接字联网API》** (W. Richard Stevens)
   * *重点研读*：第 6 章（I/O 复用：select 与 poll）、第 7 章（套接字选项 SO_REUSEADDR/TCP_NODELAY）、第 16 章（非阻塞式 I/O）。
2. **《Linux多线程服务端编程：使用muduo C++网络库》** (陈硕)
   * *重点研读*：第 1 章（线程安全的对象生命期管理、`shared_from_this` 弱回调）、第 7.4 节（Buffer 仿 Netty 读写双指针设计）。
3. **《Effective Modern C++》** (Scott Meyers)
   * *重点研读*：条款 23~30（深入理解 std::move、std::forward、通用引用与移动语义优化）。

### 2.3 工业级优秀开源项目对照学习
* **Muduo** (`chenshuo/muduo`)：学习 One Loop Per Thread 思想与经典 C++ 网络封装。
* **Glowstone** (`GlowstoneMC/Glowstone`)：Minecraft 社区著名的纯自研 Java 服务端，学习其世界物理循环与实体状态设计。
* **BungeeCord** (`SpigotMC/BungeeCord`)：大型 Minecraft 代理网关，学习其状态机路由与数据包解包逻辑。
